\begin{enumerate}[leftmargin=1mm]

\item \textbf{\large ---提交前检查---} 保存, 编译, 测过样例，测过 n=0/1；
\item 数组大小: N/M；时间空间限制；输入实数？MOD 多少？开 LL
\item \textbf{调用 \large{init}}, 清空时数组大小 (0, 1, n 还是 m, n+1)
\item 输出取模取到正值，输出格式
\item 多组没读入完就 break
\item 关流同步, 注意不要关流同步混用
\item 加上需要怀疑的 \texttt{assert}
\item 开 \texttt{Ofast}，位运算开 \texttt{target("abm")}
\end{enumerate}
\begin{enumerate}[leftmargin=1mm]
\setlength{\itemsep}{0pt}
\setlength{\parskip}{0.5pt}
\item \textbf{\large ---提交后检查---} 变量复用后忘记改回去
\item sum 多组输入: 应只用了输入内容 (memset TL, 错下标 WA), 用前清空还是用后
\item int/LL 溢出, INF/-1 大小，浮点数 eps 和 = 0, \texttt{\_\_builtin\_popcount\large{ll}}
\item 类似 \texttt{pair <LL, int> x = pair <int, int>();} 不会报警告 
\item 离散化与二分: \texttt{lower\_bound upper\_bound +-1}, begin(), end()
\item 自定义排序：排序方向，比较函数为小于，考虑坏点: 如叉积 (0, 0)
\item 样例是否为对称/回文的？考虑构造不对称的情况，正序逆序
\item 复制过的代码对应位置正确修改
\item 检查 shadow 变量重名
\item 分类讨论: if 嵌套, break 位置
\item 图: 边标号初始是否为 1, 单双向边, 反向边边权
\item 几何: 共线, sqrt(-0.0), nan / inf, 重点, 除零 det/dot, 旋转方向
\item 浮点数：eps 量纲：应当至少取到（最短线段 $\times$ 精度要求）。
\item 二分，三分：次数。
